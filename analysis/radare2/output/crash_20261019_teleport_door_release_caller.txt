  query + 0x20A4 = 0x0170EF74 = enumerator output array in EBX.

argument - 4 CALL return - 16 enumerator saves = 0x0170CD70, recorded ESP.

The compiled caller admits this expansion only with an active provider-bearing
radio context, matching provider, query vtable 0x0106D8FC, actor zero, and tuple
(mode,disposition) in {(0,3),(1,1),(2,1)}. The specific tuple is not captured.
Both worldspace-cell and direct-cell branches merge at CALL ESI. This is the
optimized expansion, not the original-provider fallback at 0x100611E3.
A source-level unwind is unnecessary for this physical ABI proof.
The offending reference identity/base writer remain unknown.
