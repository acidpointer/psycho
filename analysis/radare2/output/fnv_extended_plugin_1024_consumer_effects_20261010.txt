Scenario payload arithmetic:
- 1024 * 4-byte selected pointers = 4096 bytes, outside native inline storage.
- 1024 * 256 * 4-byte selector tokens = 1048576 bytes excluding clones.
- 1024 owners times 2^24 possible locals = 2^34 canonical combinations.
  This is the full possible domain, not a record count in any actual workload.
- Four-byte dense handles per 24-bit local domain = 64 MiB per owner;
  1024 domains = 64 GiB. Sparse admitted handles avoid this dense allocation.
Native 23-bit save ordinals and separate 16-bit dictionary domain are unchanged
by choosing a 1024-file scenario; they remain record-domain admission gates.
