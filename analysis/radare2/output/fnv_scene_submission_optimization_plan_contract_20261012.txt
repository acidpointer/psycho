Read-only native research. No production change, native execution, profiling,
elapsed-time result, or implementation qualification is recorded here.
Radare2 MCP was primary. Bounded .rdata byte searches discovered pointers;
subsequent MCP table reads and constructor writes qualify the used tables.
Empty xrefs do not establish absence of indirect callers or complete coverage.
Instruction counts often include adjacent functions/data after a return.
Automatically inferred argument labels and function names are not ABI proof.
Some large captures may be clipped; only printed aligned instructions are used.

Corrections and excluded exploratory labels:
- B99A90 is O(1) prepend, not sorted insertion; B99B00 is O(1) append.
- B99770 inserts active categories with a comparator; it is called when a
  pass group is empty, not for every geometry/pass entry.
- E88DC0 returns without packing when ordinary geometry data +0x34 is present.
  Its six-argument RET 0x18 contract overrides the inferred four-argument label.
- E72C20 is geometry renderer-path eligibility, not GPU occlusion.
- The old tentative shader base 10BC074 is four bytes beyond the actual
  constructor-published table 10BC070. Its +0x78 is BD4890, +0x7C is BD4BA0,
  +0x6C is E812F0 and +0x8C is A89AF0.
- E812F0 prepares/binds resources; it is not a primitive draw.
- The labels "geometry draw forwarding" (A8F3F0) and "D3D shader draw loop"
  (E87010) were discovery labels. A8F3F0 is a return stub; E87010 is a
  constant-map entry lookup. Neither qualifies primitive submission.
- 10EF568 is inside the constant-map table, not its base. B7E330 publishes
  base 10EF544 at B7E366; E87690 also writes that base.
- E878C0 is insertion, not defined-constant calculation. E84B60 handles
  constant data, not predefined evaluation. The confirmed predefined evaluator
  is E83DB0 through constant-map +0x8C. E84BA0 handles attributes;
  E84D00 handles global values. Use table 10EF544, not candidate labels.
- The 10EFB0C probe returned a string, not a renderer vtable. It is excluded.
  Actual renderer base 10EE4BC is constructor-published. Slots at 10EE670/674
  contain E745A0/E74840, offsets +0x1B4/+0x1B8.
- NiTriShape factory A744D0 publishes table 109D454 at A744EB; slot +0xE0
  at 109D534 contains A74600, which conditionally calls renderer +0x1B4.
- E8EEB0 validates stream/chip presence, not triangle primitive mode.
- E840AF is an interior arithmetic window; its exploratory label does not
  establish semantic names for the renderer matrices.

Bounded .rdata discoveries verified by MCP:
B7E400 pointer at 10EF56C; E745A0 pointer at 10EE670;
E74840 pointer at 10EE674. Discovery used PE section virtual/raw mapping,
four-byte little-endian values and .rdata bounds. Actual table identity comes
from native constructor writes, not pointer-position subtraction alone.
