Question
========
Does the native stencil contract reserve a bit that OMV may universally claim
for an exact visible-player mask?

Direct proof
============
NiDX9RenderState::ApplyStencil @ 0x00E87EF0 receives the live property as its
single stack argument and uses the cache-aware virtual SetRenderState +0x68.
For an enabled property (flags +0x18 bit 0), it publishes:

  STENCILENABLE (52): 1
  STENCILFUNC (56): flags bits 12..15 through native comparison mapping
  STENCILREF (57): complete property +0x1C value
  STENCILMASK (58): complete property +0x20 value
  STENCILFAIL (53): flags bits 1..3 through native operation mapping
  STENCILZFAIL (54): flags bits 4..6 through native operation mapping
  STENCILPASS (55): flags bits 7..9 through native operation mapping
  STENCILWRITEMASK (59): 0xFF

There is no bit excluded from the native write mask. Native properties can
select reference/test/operations affecting the full stencil byte. This proves
that the contract offers no universally reserved bit; it does not prove a
collision was observed in the owner's scene.

An OMV stencil carrier would need a separately proven exclusivity policy over
all consuming material paths, full-clear lifetime and later occluding draws.
Using bit 0x80 merely because it is often unused is not authorized by this
contract. Restoring only raw D3D state also requires cache coherence: the native
SetRenderState @ 0x00E88780 caches values at this+0x120+state*8 and calls the
actual device only when the cached value changes.

The existing RenderTriShape entry @ 0x00E745A0 was rechecked. It reads the
geometry's skin instance at +0xBC and submits the skinned partition branch
through actual DrawIndexedPrimitive at 0x00E746AB. Consequently the separate
shadow draw_skinned helper is not evidence that normal player skin bypasses
this existing color hook. This proves the shown branch, not completeness of
all material/color paths.

Unresolved
==========
- Exact fragment coverage and later occlusion across every player material.
- Translucent-player sharpness/composition semantics.
- An independent mask carrier preserving native shader, alpha, blend, depth,
  stencil and cache behavior without per-draw readbacks or routine allocation.
- Actual game-only image and performance behavior (not run).
